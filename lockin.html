Lock In

A Windows app that plays your music while you're dead or in menus, and pauses it the instant the round goes live — for Valorant, League of Legends and Marvel Rivals.

  • 3games, each with its own state adapter
  • ~10 msper screen read with Windows' built-in OCR
  • 0runtime dependencies — Electron and nothing else
  • Reads death from the game itself: Riot's local API for League, and OCR of the on-screen "KILLED BY" banner for Valorant and Marvel Rivals.
  • Hype mode reads the HUD's alive counters off the screen and drops your hype track when it's down to a 1v1 clutch.
  • Controls Spotify, YouTube or any player through Windows' own media layer — no account or API key. Verified against a full 61-round Valorant match.
Electron · Node.js · Windows OCR & media APIs · PowerShell
